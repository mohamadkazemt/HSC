# ماژول ارزیابی ریسک هوشمند (Smart Risk Assessment)

## 📋 توضیحات کلی
این ماژول سیستم **هوشمند** ارزیابی ریسک HSE است که از داده‌های واقعی آنومالی‌ها و حوادث برای تحلیل و پیشنهاد استفاده می‌کند.

## 🧠 قابلیت‌های هوشمند جدید

### 1. **تحلیل خطرات پرتکرار**
- شناسایی خودکار خطراتی که در 90 روز گذشته بیش از 3 بار گزارش شده‌اند
- نمایش تعداد آنومالی‌های ایمن و ناایمن
- پیشنهاد اولویت‌بندی بر اساس فراوانی

```python
# مثال: خطرات پرتکرار
high_frequency_hazards = get_high_frequency_hazards(days=90, min_count=3)
# نتیجه: لیستی از خطراتی که باید ارزیابی شوند
```

### 2. **تحلیل مبتنی بر حوادث واقعی**
- استخراج خطرات از حوادث 12 ماه گذشته
- محاسبه شدت بر اساس نوع آسیب واقعی
- ماتریس هوشمند تبدیل نوع آسیب به عدد شدت (1-5)

```python
# ماتریس شدت خودکار
'مرگ' -> 5
'قطع عضو' -> 4
'شکستگی' -> 3
'کوفتگی' -> 2
'خراش' -> 1
```

### 3. **پیشنهاد احتمال هوشمند**
- محاسبه احتمال وقوع بر اساس تعداد آنومالی‌های گذشته
- فیلتر بر اساس مکان و زمان
- پیشنهاد خودکار عدد احتمال (1-5)

```python
# تبدیل هوشمند تعداد به احتمال
count >= 10 -> احتمال 5 (خیلی زیاد)
count >= 6  -> احتمال 4 (زیاد)
count >= 3  -> احتمال 3 (متوسط)
count >= 1  -> احتمال 2 (کم)
count == 0  -> احتمال 1 (خیلی کم)
```

### 4. **مکان‌های حساس**
- شناسایی خودکار مکان‌هایی با بیشترین آنومالی
- ردیابی حوادث واقعی در هر مکان
- هشدار برای مکان‌های پرخطر

### 5. **پیشنهاد ریسک برای مشاغل**
- تحلیل آنومالی‌های تاریخی مربوط به هر شغل
- استخراج حوادث مرتبط با شغل
- پیشنهاد خودکار ریسک‌های احتمالی

### 6. **تحلیل روند (Trend Analysis)**
- نمودار روند آنومالی‌ها در 6 ماه گذشته
- تشخیص روند صعودی/نزولی/ثابت
- محاسبه درصد آنومالی‌های ناایمن

### 7. **بینش‌های هوشمند (Smart Insights)**
برای هر ریسک، سیستم به صورت خودکار:
- آنومالی‌های مرتبط را پیدا می‌کند
- حوادث مشابه را نمایش می‌دهد
- روند را تحلیل می‌کند
- پیشنهادات اقدام ارائه می‌دهد

```python
insights = {
    'anomaly_trend': {'trend': 'increasing', 'unsafe_percentage': 60},
    'related_anomalies': [anomaly1, anomaly2, ...],
    'related_incidents': [incident1, incident2, ...],
    'suggestions': [
        {'type': 'warning', 'message': 'روند رو به افزایش'},
        {'type': 'danger', 'message': '60% ناایمن'},
    ]
}
```

## 📊 ساختار دیتابیس

### مدل `RiskAssessment`
**فیلدهای اصلی:**
- `position`: شغل/سمت (FK)
- `risk_source`: منشا شناسایی (13 نوع)
- `activity_component`: فعالیت
- `hazard`: خطر (FK به AnomalyDescription)
- `people_at_risk`: افراد در معرض خطر (M2M)
- `potential_event`: رویداد محتمل
- `consequence`: پیامد (FK به InjuryType)

**محاسبه ریسک:**
- `probability`: احتمال (1-5)
- `severity`: شدت (1-5)
- `risk_number`: عدد ریسک (خودکار)
- `risk_level`: سطح ریسک (خودکار)

**کنترل‌های پیشنهادی:**
- `control_elimination`
- `control_substitution`
- `control_engineering`
- `control_admin`
- `control_ppe`

**ارزیابی مجدد:**
- `residual_probability`
- `residual_severity`
- `residual_risk_number` (خودکار)

## 🎯 نحوه استفاده

### 1. ایجاد ریسک جدید
1. به داشبورد بروید
2. شغل مورد نظر را انتخاب کنید
3. "ریسک جدید" را کلیک کنید
4. فرم را پر کنید (احتمال و شدت الزامی است)
5. ذخیره کنید - RPN به صورت خودکار محاسبه می‌شود

### 2. ارزیابی مجدد
پس از اجرای اقدامات اصلاحی:
1. وارد جزئیات ریسک شوید
2. "ارزیابی مجدد" را کلیک کنید
3. احتمال و شدت جدید را وارد کنید
4. ریسک باقی‌مانده محاسبه می‌شود

### 3. فیلتر کردن
در صفحه لیست ریسک‌ها می‌توانید بر اساس:
- سطح ریسک
- منشا شناسایی
- روتین / غیر روتین
- نیاز به اقدام اصلاحی

فیلتر کنید.
