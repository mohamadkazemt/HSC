# راهنمای استفاده از Management Command بهینه‌سازی تصاویر

## دستور پایه

```bash
python manage.py optimize_anomaly_images
```

این دستور تمام تصاویر آنومالی‌های موجود در دیتابیس را بهینه‌سازی می‌کند.

## گزینه‌های موجود

### 1. حالت Dry-Run (نمایش بدون تغییر)

برای مشاهده اینکه چه تغییراتی انجام خواهد شد بدون اعمال تغییرات واقعی:

```bash
python manage.py optimize_anomaly_images --dry-run
```

### 2. تنظیم حداکثر حجم

برای تنظیم حداکثر حجم فایل به مگابایت (پیش‌فرض: 1 MB):

```bash
python manage.py optimize_anomaly_images --max-size 0.5
```

این دستور تصاویر را به حداکثر 0.5 مگابایت فشرده می‌کند.

### 3. تنظیم کیفیت

برای تنظیم کیفیت فشرده‌سازی (1-100، پیش‌فرض: 85):

```bash
python manage.py optimize_anomaly_images --quality 75
```

کیفیت پایین‌تر = فشرده‌سازی بیشتر ولی کیفیت تصویر کمتر

### 4. محدود کردن تعداد

برای پردازش تعداد محدودی از تصاویر (برای تست):

```bash
python manage.py optimize_anomaly_images --limit 10
```

این دستور فقط 10 تصویر اول را پردازش می‌کند.

## ترکیب گزینه‌ها

می‌توانید چندین گزینه را با هم ترکیب کنید:

```bash
python manage.py optimize_anomaly_images --dry-run --max-size 0.8 --quality 80 --limit 50
```

## مثال‌های کاربردی

### مثال 1: بررسی اولیه
ابتدا ببینید چه تغییراتی انجام می‌شود:

```bash
python manage.py optimize_anomaly_images --dry-run
```

### مثال 2: تست روی تعداد محدود
روی 5 تصویر اول تست کنید:

```bash
python manage.py optimize_anomaly_images --limit 5
```

### مثال 3: فشرده‌سازی قوی
برای فشرده‌سازی بیشتر با کیفیت متوسط:

```bash
python manage.py optimize_anomaly_images --max-size 0.5 --quality 75
```

### مثال 4: فشرده‌سازی با کیفیت بالا
برای حفظ کیفیت بالاتر:

```bash
python manage.py optimize_anomaly_images --max-size 1.5 --quality 90
```

## خروجی دستور

دستور اطلاعاتی شامل موارد زیر را نمایش می‌دهد:

- تعداد کل تصاویر
- پیشرفت پردازش (با نمایش درصد)
- حجم قبل و بعد از بهینه‌سازی برای هر تصویر
- خلاصه کلی در پایان:
  - تعداد بهینه‌سازی شده
  - تعداد رد شده (نیاز به بهینه‌سازی نداشته)
  - تعداد خطاها
  - کل حجم ذخیره شده

## نکات مهم

1. **پشتیبان‌گیری**: قبل از اجرای دستور، از فولدر `media` پشتیبان بگیرید
2. **تست ابتدایی**: ابتدا با `--dry-run` و `--limit` تست کنید
3. **زمان اجرا**: اجرای دستور برای تعداد زیاد تصویر ممکن است زمان‌بر باشد
4. **فضای دیسک**: مطمئن شوید فضای کافی برای فایل‌های موقت دارید
5. **دسترسی فایل**: مطمئن شوید Django به فایل‌های مدیا دسترسی خواندن/نوشتن دارد

## عیب‌یابی

### خطا: "فایل وجود ندارد"
- مسیر `MEDIA_ROOT` را در `settings.py` بررسی کنید
- مطمئن شوید فایل‌های تصویر واقعاً موجود هستند

### خطا: "Permission denied"
- دسترسی‌های فایل را بررسی کنید
- در لینوکس: `sudo chown -R www-data:www-data media/`

### فشرده‌سازی انجام نمی‌شود
- Pillow نصب باشد: `pip install Pillow`
- حجم فایل قبلاً کوچک است (کمتر از max-size)

## اتوماسیون

برای اجرای خودکار دوره‌ای، می‌توانید از Cron Job استفاده کنید:

```bash
# هر شنبه ساعت 3 صبح
0 3 * * 6 cd /path/to/project && python manage.py optimize_anomaly_images --max-size 1 --quality 85
```

یا با Django Celery Beat:

```python
# در settings.py یا celery config
CELERY_BEAT_SCHEDULE = {
    'optimize-anomaly-images-weekly': {
        'task': 'anomalis.tasks.optimize_images',
        'schedule': crontab(hour=3, minute=0, day_of_week=6),
    },
}
```
