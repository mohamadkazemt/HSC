1. Create Emergency Groups:
   $ cd /home/mohamadkazem/HSC
   $ python manage.py setup_emergency_portal

2. Create First User (Django Shell):
   $ python manage.py shell
   >>> from django.contrib.auth.models import User, Group
   >>> user = User.objects.create_user('doctor_test', password='test123')
   >>> group = Group.objects.get(name='EmergencyDoctor')
   >>> user.groups.add(group)

3. Run Server:
   $ python manage.py runserver

⚠️ TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problem: Groups not found
Solution: Run `python manage.py setup_emergency_portal`

Problem: Login fails
Solution: Check if user is in emergency group:
  >>> user.groups.filter(name__contains='Emergency')

Problem: API returns 403
Solution: 
  • Check user is logged in
  • Check permissions are configured
  • Check CSRF token is included (for POST)

Problem: Date format error
Solution: Use format: 1404/12/29 for dates, 1404/12/29 12:30:00 for datetime
