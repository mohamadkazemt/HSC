# راهنمای استفاده از سیستم برنامه‌ریزی چک‌لیست

## خلاصه

سیستم به صورت **کاملاً خودکار** کار می‌کند. شما فقط باید برنامه‌های زمان‌بندی را در رابط کاربری ایجاد کنید و بقیه کارها به صورت خودکار انجام می‌شود.

## مراحل استفاده

### مرحله 1: ایجاد برنامه زمان‌بندی (از رابط کاربری)

1. **ورود به سیستم** و رفتن به منوی:
   - واحد ایمنی (HSEC) → مدیریت چک‌لیست → **برنامه‌های زمان‌بندی**

2. **کلیک روی "ایجاد برنامه جدید"**

3. **پر کردن فرم:**
   - **نام برنامه**: مثلاً "چک‌لیست ماهانه ماشین A"
   - **نوع چک‌لیست**: ماشین / مکان / ماشین‌آلات پیمانکار
   - **نوع برنامه‌ریزی**: 
     - **روزهای مشخص ماه**: مثلاً `1, 15` (اول و پانزدهم هر ماه)
     - **تاریخ‌های مشخص**: مثلاً `2024-12-25, 2025-01-01`
     - **هفتگی**: هر دوشنبه
   - **هدف**: انتخاب ماشین/مکان/خودرو
   - **فعال**: تیک بزنید تا برنامه فعال شود

4. **ذخیره**: با کلیک روی "ایجاد"

### مرحله 2: فعال‌سازی Celery Beat (یک بار)

برای اینکه instances به صورت خودکار ایجاد شوند، باید Celery Beat را فعال کنید:

```bash
# در ترمینال/PowerShell
celery -A HSCprojects beat -l info
```

**نکته مهم:** این دستور باید همیشه در حال اجرا باشد. می‌توانید آن را به عنوان سرویس Windows یا با استفاده از supervisor/systemd اجرا کنید.

### مرحله 3: مشاهده چک‌لیست‌های در انتظار

کاربران (بازرسان ایمنی) می‌توانند:

1. **چک‌لیست‌های در انتظار** را در منو مشاهده کنند:
   - واحد ایمنی → مدیریت چک‌لیست → **چک‌لیست‌های در انتظار**

2. **چک‌لیست‌های آینده** را ببینند:
   - واحد ایمنی → مدیریت چک‌لیست → **چک‌لیست‌های آینده**

3. **شروع چک‌لیست**: با کلیک روی "شروع چک‌لیست" در کارت مربوطه

## مثال عملی

### سناریو: چک‌لیست ماهانه ماشین

1. **ایجاد برنامه:**
   - نام: "چک‌لیست ماهانه ماشین A"
   - نوع: ماشین
   - برنامه‌ریزی: روزهای مشخص ماه
   - روزهای ماه: `1, 15`
   - هدف: ماشین A
   - فعال: ✓

2. **سیستم خودکار:**
   - هر روز ساعت 00:00، Celery Beat task اجرا می‌شود
   - در روز 1 و 15 هر ماه، instance جدید با `due_date = همان روز` ایجاد می‌شود
   - بازرسان ایمنی در شیفت روزکار، این instances را در صفحه "چک‌لیست‌های در انتظار" می‌بینند

3. **تکمیل چک‌لیست:**
   - بازرس A یا B می‌تواند چک‌لیست را تکمیل کند
   - با تکمیل، instance به "completed" تبدیل می‌شود
   - از لیست بازرس دیگر حذف می‌شود

## مدیریت برنامه‌های زمان‌بندی

### ویرایش برنامه
- در لیست برنامه‌ها، روی آیکون "ویرایش" کلیک کنید
- تغییرات را اعمال و ذخیره کنید

### فعال/غیرفعال کردن
- روی آیکون "فعال/غیرفعال" کلیک کنید
- برنامه‌های غیرفعال، instances ایجاد نمی‌کنند

### حذف برنامه
- روی آیکون "حذف" کلیک کنید
- **توجه**: این عمل غیرقابل بازگشت است

## سوالات متداول

### Q: آیا باید هر روز دستی instances ایجاد کنم؟
**A:** خیر! اگر Celery Beat فعال باشد، به صورت خودکار انجام می‌شود.

### Q: اگر Celery Beat را اجرا نکنم چه می‌شود؟
**A:** می‌توانید از Management Command استفاده کنید:
```bash
python manage.py create_scheduled_instances --days-ahead 30
```

### Q: چطور مطمئن شوم که Celery Beat در حال اجرا است؟
**A:** در لاگ‌های Celery Beat باید پیام‌های زیر را ببینید:
```
[INFO] Task checklist_app.tasks.create_scheduled_checklist_instances succeeded
```

### Q: چک‌لیست‌های آینده تا چند روز نمایش داده می‌شوند؟
**A:** تا 30 روز آینده

### Q: آیا می‌توانم برای یک ماشین چند برنامه زمان‌بندی داشته باشم؟
**A:** بله، می‌توانید چندین برنامه برای یک ماشین ایجاد کنید.

## نکات مهم

1. **Celery Beat باید همیشه در حال اجرا باشد** تا instances به صورت خودکار ایجاد شوند
2. **برنامه‌های غیرفعال** instances ایجاد نمی‌کنند
3. **تغییرات در برنامه** فقط روی instances آینده تأثیر می‌گذارد (instances قبلی تغییر نمی‌کنند)
4. **حذف برنامه** instances قبلی را حذف نمی‌کند، فقط از ایجاد instances جدید جلوگیری می‌کند
