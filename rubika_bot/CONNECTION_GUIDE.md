# راهنمای اتصال به ربات روبیکا

## روش‌های اتصال

### روش 1️⃣: لینک مستقیم (ساده‌ترین روش) ⭐

1. به پنل کاربری خود بروید
2. روی دکمه "اتصال سریع" کلیک کنید
3. لینک به صورت خودکار باز می‌شود و ربات را باز می‌کند
4. پیام `/start` به صورت خودکار ارسال می‌شود و اتصال برقرار می‌شود

**مزایا:**
- ✅ ساده و سریع
- ✅ نیاز به تایپ کد ندارد
- ✅ فقط یک کلیک

### روش 2️⃣: کد اتصال

1. به پنل کاربری خود بروید
2. کد اتصال را کپی کنید
3. در ربات روبیکا دستور زیر را ارسال کنید:
   ```
   /connect [کد]
   ```
   یا
   ```
   /start [کد]
   ```

**مزایا:**
- ✅ می‌توانید کد را ذخیره کنید
- ✅ می‌توانید از هر دستگاهی استفاده کنید

### روش 3️⃣: از طریق پنل ادمین

1. به پنل ادمین بروید
2. بخش "Rubika Bot Settings" را باز کنید
3. روی "تست اتصال سریع" کلیک کنید
4. لینک به صورت خودکار باز می‌شود

## نکات مهم

### ⏰ انقضای کد
- کد اتصال 60 دقیقه اعتبار دارد
- بعد از انقضا باید کد جدید دریافت کنید

### 🔄 اتصال مجدد
- اگر قبلاً متصل شده‌اید، می‌توانید با کد جدید اتصال را تغییر دهید
- برای قطع اتصال از دستور `/disconnect` استفاده کنید

### ❓ مشکل در اتصال؟
1. بررسی کنید که کد منقضی نشده باشد
2. بررسی کنید که کد قبلاً استفاده نشده باشد
3. کد جدید دریافت کنید
4. لاگ‌های webhook را در پنل ادمین بررسی کنید

## دستورات مفید

- `/start` - شروع کار با ربات
- `/connect [کد]` - اتصال با کد
- `/account` یا `/status` - مشاهده وضعیت اتصال
- `/disconnect` - قطع اتصال
- `/help` - راهنمای کامل

## API Endpoints

### دریافت لینک اتصال
```http
POST /rubika-bot/get-connection-link/
```

**Response:**
```json
{
  "ok": true,
  "code": "abc123...",
  "link": "https://rubika.ir/bot_username?start=abc123...",
  "expires_at": "2025-01-01T12:00:00Z",
  "instructions": "روی لینک زیر کلیک کنید..."
}
```

### دریافت کد اتصال
```http
POST /rubika-bot/generate-code/
```

**Response:**
```json
{
  "ok": true,
  "code": "abc123...",
  "expires_at": "2025-01-01T12:00:00Z"
}
```
