# راهنمای اتصال کاربران به ربات روبیکا

## ⚠️ مشکل فعلی
هیچ کاربری به ربات روبیکا متصل نیست، بنابراین پیام‌های تایید/رد مرخصی ارسال نمی‌شود.

## ✅ راه‌حل: اتصال کاربران به ربات

### مرحله 1: دریافت لینک اتصال
1. به صفحه پروفایل خود بروید: `/accounts/profile/`
2. در بخش "اتصال به ربات روبیکا" روی دکمه "دریافت لینک اتصال" کلیک کنید
3. یک کد یکبار مصرف برای شما ایجاد می‌شود

### مرحله 2: اتصال در روبیکا
1. روی لینک کلیک کنید یا کد را کپی کنید
2. در ربات روبیکا دستور `/connect [کد]` را ارسال کنید
3. پیام تأیید اتصال را دریافت می‌کنید

### دستور مستقیم
```
/connect YOUR_CODE_HERE
```

## 📱 راه‌حل سریع برای تست

### برای تست کردن سیستم:
1. یک کاربر (مثلاً خودتان) را به ربات متصل کنید
2. یک درخواست مرخصی ایجاد کنید و خودتان را به عنوان جایگزین انتخاب کنید
3. باید پیام با دکمه‌های تایید/رد را دریافت کنید

## 🔧 اتصال از طریق دستورات Django

### بررسی کاربران متصل:
```bash
python manage.py check_rubika_connections
```

### اتصال دستی یک کاربر (برای تست):
```python
from django.contrib.auth.models import User
from rubika_bot.models import RubikaUser

# پیدا کردن کاربر
user = User.objects.get(username='USERNAME')

# ایجاد یا به‌روزرسانی پروفایل روبیکا
rubika_user, created = RubikaUser.objects.get_or_create(
    chat_id='YOUR_CHAT_ID',  # Chat ID از ربات روبیکا
    defaults={
        'user': user,
        'first_name': user.first_name,
        'last_name': user.last_name
    }
)

if not created:
    rubika_user.user = user
    rubika_user.save()
```

## 📝 نکات مهم

1. **کد اتصال یکبار مصرف است** و بعد از استفاده یا 30 دقیقه منقضی می‌شود
2. **هر کاربر باید جداگانه متصل شود**
3. **بدون اتصال، فقط نوتیفیکیشن وب ارسال می‌شود** و پیام روبیکا ارسال نمی‌شود
4. **لاگ‌ها نشان می‌دهند** که آیا کاربر پروفایل روبیکا دارد یا خیر

## 🔍 بررسی وضعیت

### در کد:
```python
# بررسی اینکه کاربر متصل است یا خیر
user = User.objects.get(username='USERNAME')
rubika_profile = getattr(user, 'rubika_profile', None)

if rubika_profile and rubika_profile.chat_id:
    print(f"✅ کاربر متصل است - Chat ID: {rubika_profile.chat_id}")
else:
    print("⚠️ کاربر به ربات متصل نیست")
```

### در لاگ‌های سرور:
وقتی درخواست مرخصی ثبت می‌شود، این لاگ‌ها را ببینید:
```
🔍 Checking Rubika profile for user USERNAME
   - Has rubika_profile: True/False
   - Chat ID: ...
📤 Sending leave approval request to Rubika bot
```

## ⚡ راه‌حل فوری برای تست

اگر می‌خواهید فوراً تست کنید:

1. **شما (mkt) را متصل کنید:**
   - برو به `/accounts/profile/`
   - لینک اتصال بگیر
   - در ربات بزن: `/connect [کد]`

2. **یک درخواست تست بساز:**
   - نوع: مرخصی استحقاقی
   - جایگزین: خودت (mkt)
   - ثبت کن

3. **پیام را در ربات دریافت کن:**
   - باید پیامی با دکمه‌های "✅ تایید" و "❌ رد" ببینی
   - روی دکمه‌ها کلیک کن تا تست کنی

## 🎯 اتصال همه کاربران

برای اتصال تمام کاربران:
1. به همه کاربران اطلاع دهید که به ربات متصل شوند
2. لینک ربات را در سایت قرار دهید
3. راهنمای تصویری بسازید
4. در قسمت داشبورد هشدار نمایش دهید اگر متصل نیستند
