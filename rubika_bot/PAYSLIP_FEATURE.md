# قابلیت دریافت فیش حقوقی در ربات روبیکا

## نمای کلی

این قابلیت به کاربران متصل به ربات اجازه می‌دهد تا فیش‌های حقوقی خود را مستقیماً از طریق ربات روبیکا دریافت کنند.

## ویژگی‌ها

### ✅ امنیت
- فقط کاربران متصل به حساب کاربری می‌توانند فیش‌های خود را دریافت کنند
- هر کاربر فقط به فیش‌های خودش دسترسی دارد
- تمام دسترسی‌ها لاگ می‌شوند

### 📋 قابلیت‌ها
- نمایش لیست فیش‌های حقوقی موجود (تا 12 ماه اخیر)
- نمایش ماه و سال به صورت شمسی
- ارسال فایل فیش حقوقی به صورت مستقیم در ربات
- پشتیبانی از فرمت‌های مختلف فایل (PDF، تصاویر، و غیره)

## نحوه استفاده

### برای کاربران

1. **اتصال به حساب کاربری**
   - ابتدا باید به حساب کاربری خود متصل شوید
   - از دکمه "🔗 اتصال" یا دستور `/connect [کد]` استفاده کنید

2. **دریافت فیش حقوقی**
   - روی دکمه "💰 فیش حقوقی" کلیک کنید
   - لیست ماه‌های موجود نمایش داده می‌شود
   - روی ماه مورد نظر کلیک کنید
   - فایل فیش حقوقی ارسال می‌شود

### دکمه‌های ربات

برای کاربران متصل، دکمه‌های زیر در دسترس است:

```
🔄 شروع          📊 وضعیت
💰 فیش حقوقی    ❌ قطع اتصال
📖 راهنما
```

## معماری فنی

### Handler ها

#### 1. `_handle_payslip_request`
- نمایش لیست فیش‌های حقوقی موجود
- بررسی اتصال کاربر
- ساخت کیبورد با دکمه‌های ماه‌ها
- محدودیت: حداکثر 12 ماه اخیر

#### 2. `_send_payslip_file`
- دریافت فایل فیش حقوقی از دیتابیس
- بررسی دسترسی کاربر
- ارسال فایل به کاربر از طریق `rubpy.send_file`

### جریان کار

```
کاربر کلیک روی "💰 فیش حقوقی"
    ↓
بررسی اتصال کاربر
    ↓
دریافت لیست فیش‌ها از دیتابیس
    ↓
نمایش کیبورد با ماه‌های موجود
    ↓
کاربر انتخاب ماه
    ↓
دریافت فایل فیش از دیتابیس
    ↓
ارسال فایل به کاربر
```

### مدل‌های استفاده شده

- `RubikaUser`: اطلاعات کاربر ربات
- `accounts.UserProfile`: پروفایل کاربر در سیستم
- `accounts.Payslip`: فیش‌های حقوقی

### متدهای کلیدی

```python
# نمایش لیست فیش‌ها
async def _handle_payslip_request(self, chat_id: str, user: RubikaUser) -> None

# ارسال فایل فیش
async def _send_payslip_file(self, chat_id: str, user: RubikaUser, button_id: str) -> None
```

## فرمت دکمه‌ها

دکمه‌های انتخاب ماه به فرمت زیر هستند:

```
button_id: payslip_YYYY_MM
مثال: payslip_1403_8  (آبان 1403)
```

## پیام‌های خطا

| خطا | پیام |
|-----|------|
| کاربر متصل نیست | ⚠️ برای دریافت فیش حقوقی، ابتدا باید به حساب کاربری خود متصل شوید. |
| پروفایل یافت نشد | ⚠️ پروفایل کاربری شما یافت نشد. لطفاً با پشتیبانی تماس بگیرید. |
| فیش موجود نیست | 📭 هیچ فیش حقوقی برای شما ثبت نشده است. |
| خطا در شناسایی | ❌ خطا در شناسایی فیش حقوقی. |
| فیش یافت نشد | ❌ فیش حقوقی مورد نظر یافت نشد. |
| فایل موجود نیست | ❌ فایل فیش حقوقی موجود نیست. |
| خطا در ارسال | ❌ خطا در ارسال فایل. لطفاً از طریق پنل وب اقدام کنید. |

## لاگ‌ها

تمام عملیات دریافت فیش حقوقی لاگ می‌شوند:

```python
logger.info(f"Sent payslip file to {chat_id}: {year}/{month}")
logger.error(f"Error sending payslip file via rubpy: {e}", exc_info=True)
```

## تست

برای تست این قابلیت:

1. یک کاربر ایجاد کنید و به ربات متصل کنید
2. از پنل ادمین یک فیش حقوقی برای کاربر آپلود کنید
3. در ربات روی "💰 فیش حقوقی" کلیک کنید
4. بررسی کنید که لیست ماه‌ها نمایش داده می‌شود
5. روی یک ماه کلیک کنید
6. بررسی کنید که فایل ارسال می‌شود

## ملاحظات امنیتی

### ✅ بررسی‌های انجام شده
- بررسی اتصال کاربر به حساب کاربری
- بررسی تعلق فیش به همان کاربر
- استفاده از `sync_to_async` برای عملیات دیتابیس
- لاگ کردن تمام عملیات

### ⚠️ نکات مهم
- فایل‌های فیش حقوقی در سرور ذخیره می‌شوند
- دسترسی مستقیم به فایل‌ها از طریق URL باید غیرفعال باشد (مطابق `PAYSLIP_SECURITY.md`)
- فقط از طریق Django view یا ربات قابل دسترسی است

## وابستگی‌ها

- `rubpy`: برای ارسال فایل
- `accounts.models`: برای دسترسی به فیش‌های حقوقی
- `asgiref.sync.sync_to_async`: برای عملیات async

## محدودیت‌ها

- حداکثر 12 ماه اخیر نمایش داده می‌شود
- هر ردیف کیبورد حداکثر 2 دکمه دارد
- فرمت فایل باید توسط روبیکا پشتیبانی شود

- فرمت‌های خاص ممکن است توسط روبیکا پشتیبانی نشوند

## پشتیبانی

در صورت بروز مشکل:
1. لاگ‌های Celery را بررسی کنید
2. بررسی کنید که فایل فیش در سرور موجود است
3. بررسی کنید که کاربر به حساب خود متصل است
4. از پنل وب تست کنید که فیش قابل دانلود است
