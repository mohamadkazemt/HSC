# رفع مشکل "کاربر جایگزینی یافت نشد"

## 🔴 مشکل قبلی

هنگام انتخاب **مرخصی استحقاقی**، اگر کاربری در همان بخش وجود نداشت، این خطا نمایش داده می‌شد:

```
⚠️ کاربر جایگزینی در بخش شما یافت نشد.
لطفاً با مدیر خود تماس بگیرید.
```

و کاربر نمی‌توانست ادامه دهد.

---

## ✅ راه‌حل پیاده‌سازی شده

منطق انتخاب جایگزین به صورت زیر بهبود یافته است:

### مرحله 1: جستجو در بخش کاربر
ابتدا از کاربران **همان بخش (Section)** جستجو می‌شود:
- حداکثر 10 نفر
- فقط کاربران فعال (`is_active=True`)
- به غیر از خود کاربر

### مرحله 2: جستجو در کل سازمان (در صورت عدم یافتن)
اگر در بخش کاربری یافت نشد، از **کل سازمان** جستجو می‌شود:
- حداکثر 15 نفر
- مرتب شده بر اساس نام و نام خانوادگی
- فقط کاربران فعال

### مرحله 3: پیام خطا (در صورت عدم یافتن هیچ کاربری)
فقط در صورتی که **هیچ کاربر فعالی** در سیستم وجود نداشته باشد، خطا نمایش داده می‌شود.

---

## 🎯 تغییرات کد

### قبل:
```python
# فقط از همان بخش جستجو می‌کرد
if profile.section:
    users = User.objects.filter(
        userprofile__section=profile.section,
        is_active=True
    ).exclude(id=user.user.id)[:10]
    return list(users)
return []  # اگر کسی نبود، لیست خالی برمی‌گرداند
```

### بعد:
```python
# اول از بخش جستجو می‌کند
if profile.section:
    users = User.objects.filter(
        userprofile__section=profile.section,
        is_active=True
    ).exclude(id=user.user.id)[:10]
    
    if users.exists():
        return list(users), 'section'  # کاربران بخش پیدا شد

# اگر در بخش نبود، از کل سازمان جستجو می‌کند
users = User.objects.filter(
    is_active=True
).exclude(id=user.user.id).order_by('first_name', 'last_name')[:15]

if users.exists():
    return list(users), 'all'  # کاربران سازمان پیدا شد

return [], None  # هیچ کاربر فعالی وجود ندارد
```
