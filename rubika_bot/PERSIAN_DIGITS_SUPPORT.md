# پشتیبانی از اعداد فارسی و عربی در ربات Rubika

## تاریخ: 2025-11-14

## خلاصه

این سند تغییرات انجام شده برای پشتیبانی از اعداد فارسی (۰-۹) و عربی (٠-٩) در تمام ورودی‌های عددی ربات Rubika را شرح می‌دهد.

---

## 🎯 مشکل قبلی

قبل از این تغییرات، ربات **فقط اعداد انگلیسی (0-9)** را قبول می‌کرد. اگر کاربر اعداد فارسی یا عربی وارد می‌کرد، خطا دریافت می‌کرد:

### مثال‌های مشکلات قبلی:
- ❌ کد ملی: `۱۲۳۴۵۶۷۸۹۰` → خطا!
- ❌ تاریخ: `۱۴۰۳/۰۹/۱۵` → خطا!
- ❌ ساعت: `۰۸:۰۰-۱۲:۰۰` → خطا!
- ❌ کد پرسنلی: `۱۲۳۴۵` → خطا!

---

## ✅ راه‌حل

### 1️⃣ تابع `normalize_digits()`

یک تابع helper اضافه شد که **خودکار** اعداد فارسی و عربی را به انگلیسی تبدیل می‌کند:

```python
def normalize_digits(text: str) -> str:
    """
    تبدیل اعداد فارسی (۰-۹) و عربی (٠-٩) به انگلیسی (0-9)
    
    Examples:
        >>> normalize_digits("۱۴۰۳/۰۹/۱۵")
        "1403/09/15"
        >>> normalize_digits("۰۹۱۲۳۴۵۶۷۸۹")
        "09123456789"
    """
```

#### ویژگی‌های تابع:
- ✅ تبدیل اعداد فارسی: `۰۱۲۳۴۵۶۷۸۹` → `0123456789`
- ✅ تبدیل اعداد عربی: `٠١٢٣٤٥٦٧٨٩` → `0123456789`
- ✅ نگه‌داشتن متن فارسی: `کد: ۱۲۳` → `کد: 123`
- ✅ مدیریت None و رشته خالی
- ✅ سریع و کارآمد (استفاده از `str.maketrans()`)

## 📍 قسمت‌های بهبود یافته

### 1. **کد ملی** (در اتصال SMS)
```python
# قبل
national_code = national_code.strip()
if not national_code.isdigit() or len(national_code) != 10:
    # خطا!

# بعد
national_code = normalize_digits(national_code.strip())
if not national_code.isdigit() or len(national_code) != 10:
    # کار می‌کند با اعداد فارسی! ✅
```

**مثال کاربردی:**
- ورودی: `۱۲۳۴۵۶۷۸۹۰`
- پردازش: `1234567890`
- نتیجه: ✅ موفق

---

### 2. **کد پرسنلی** (در اتصال SMS و درخواست مرخصی)
```python
# قبل
personnel_code = text.strip()

# بعد
personnel_code = normalize_digits(text.strip())
```

**مثال کاربردی:**
- ورودی: `۱۲۳۴۵`
- پردازش: `12345`
- نتیجه: ✅ موفق

---

### 3. **تاریخ** (در درخواست مرخصی)
```python
# قبل
date_str = text.strip().replace(' ', '').replace('/', '-')

# بعد
date_str = normalize_digits(text.strip()).replace(' ', '').replace('/', '-')
```

**مثال‌های کاربردی:**
- ورودی: `۱۴۰۳/۰۹/۱۵` → پردازش: `1403/09/15` → ✅
- ورودی: `۱۴۰۳-۰۹-۱۵` → پردازش: `1403-09-15` → ✅
- ورودی: `1403/۰۹/15` → پردازش: `1403/09/15` → ✅ (ترکیبی)

---

### 4. **ساعت** (در مرخصی ساعتی)
```python
# قبل
match = re.match(time_pattern, text.strip())

# بعد
normalized_text = normalize_digits(text.strip())
match = re.match(time_pattern, normalized_text)
```

**مثال‌های کاربردی:**
- ورودی: `۰۸:۰۰-۱۲:۰۰` → پردازش: `08:00-12:00` → ✅
- ورودی: `08:۰۰-12:00` → پردازش: `08:00-12:00` → ✅ (ترکیبی)
- ورودی: `۱۴:۳۰ - ۱۸:۰۰` → پردازش: `14:30 - 18:00` → ✅
