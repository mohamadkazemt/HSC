# بهینه‌سازی رابط کاربری ربات Rubika

## تاریخ: 2025-11-14

## خلاصه تغییرات

این سند تغییرات انجام شده برای بهینه‌سازی رابط کاربری (UI) و تجربه کاربری (UX) ربات Rubika را شرح می‌دهد.

---

## 1️⃣ اضافه کردن دکمه "بازگشت به منوی اصلی"

### مشکل قبلی:
در بسیاری از صفحات، کاربران راهی برای بازگشت سریع به منوی اصلی نداشتند و مجبور بودند دستور `/start` را تایپ کنند.

### راه‌حل:
دکمه "🏠 بازگشت به منوی اصلی" یا "🏠 منوی اصلی" به تمام صفحات اضافه شد:

#### صفحات بهبود یافته:
- ✅ صفحه راهنما (`/help`)
- ✅ صفحه اتصال (`connect`)
- ✅ صفحه وضعیت حساب (`account`)
- ✅ صفحه قطع اتصال (`disconnect`)
- ✅ صفحه خطای فیش حقوقی (پروفایل یافت نشد، فیش موجود نیست، خطا در ارسال)
- ✅ صفحه لیست فیش‌های حقوقی
- ✅ صفحه پس از ارسال موفق فیش حقوقی
- ✅ صفحه خطای کد اتصال نامعتبر
- ✅ صفحه انصراف از درخواست مرخصی
- ✅ صفحه انصراف از رد درخواست
- ✅ صفحه انصراف از اتصال SMS
- ✅ صفحه prompt برای paste کد اتصال
- ✅ صفحه خطای کد ملی نامعتبر
- ✅ صفحه خطای کد پرسنلی نامعتبر
- ✅ پیام‌های خطا در تایید/رد درخواست مرخصی
- ✅ پیام‌های خطا در بررسی دسترسی

---

## 2️⃣ بهبود کیبورد اصلی

### تغییرات:

#### کیبورد برای کاربران **متصل**:
```
[🏠 منوی اصلی] [👤 حساب من]
[💰 فیش حقوقی] [🏖️ مرخصی]
[❓ راهنما] [🔓 قطع اتصال]
```

#### کیبورد برای کاربران **غیر متصل**:
```
[🏠 منوی اصلی] [👤 حساب من]
[🔗 اتصال با کد] [📱 اتصال با پیامک]
[❓ راهنما]
```

### بهبودها:
- ✨ ایکون‌های واضح‌تر و معنی‌دارتر
- ✨ چیدمان بهتر و منطقی‌تر
- ✨ حذف دکمه‌های غیرضروری
- ✨ دکمه "منوی اصلی" به جای "شروع"

---

## 3️⃣ بهبود پیام خوش‌آمدگویی

### پیام برای کاربران متصل:
```
👋 سلام [نام] عزیز!

✅ شما به حساب **[username]** متصل هستید.

🎯 از منوی زیر می‌توانید:
   💰 فیش حقوقی دریافت کنید
   🏖️ درخواست مرخصی ثبت کنید
   👤 وضعیت حساب را مشاهده کنید

👇 دکمه مورد نظر را انتخاب کنید:
```

### پیام برای کاربران غیر متصل:
```
👋 سلام [نام] عزیز!

🤖 به ربات خوش آمدید!

⚠️ برای استفاده از امکانات ربات، ابتدا باید به حساب کاربری خود متصل شوید.

🔗 دو روش برای اتصال:
   1️⃣ اتصال با کد (از پنل وب)
   2️⃣ اتصال با پیامک (احراز هویت)

👇 یکی از روش‌های زیر را انتخاب کنید:
```

---

## 4️⃣ بهبود پیام راهنما

### قبل:
```
📖 راهنمای ربات:

🔹 `/start` - شروع کار
🔹 `/connect [کد]` - اتصال
🔹 `/account` - وضعیت
🔹 `/disconnect` - قطع اتصال
🔹 `/help` - راهنما
```

### بعد:
```
📖 راهنمای ربات:

🔹 `/start` - بازگشت به منوی اصلی
🔹 `/connect [کد]` - اتصال با کد
🔹 `/account` - مشاهده وضعیت حساب
🔹 `/disconnect` - قطع اتصال
🔹 `/help` - نمایش راهنما

💡 می‌توانید از دکمه‌های زیر نیز استفاده کنید:
```

## 5️⃣ بهبود پیام‌های plain text

### پاسخ به سلام:
- **متصل**: `👋 سلام [نام] عزیز! ✨ چطور می‌تونم کمکت کنم؟`
- **غیر متصل**: `👋 سلام [نام] عزیز! ⚠️ لطفاً ابتدا به حساب کاربری خود متصل شوید.`

### پاسخ به تشکر:
`🌟 خواهش می‌کنم [نام]! خوشحالیم که تونستیم کمکتون کنیم. 😊`

### پاسخ به خداحافظی:
`👋 خداحافظ [نام]! موفق باشید. 🌟`

### پاسخ به سایر پیام‌ها:
- **متصل**: `💬 پیام شما دریافت شد: "[متن]" 💡 از دکمه‌های منو برای دسترسی سریع استفاده کنید.`
- **غیر متصل**: `💬 پیام شما دریافت شد: "[متن]" ⚠️ برای استفاده از امکانات ربات، لطفاً ابتدا وصل شوید.`

---

## 6️⃣ بهبود پیام‌های خطا

### ویژگی‌های جدید:
- ✅ همه پیام‌های خطا شامل دکمه بازگشت به منوی اصلی
- ✅ پیام‌های واضح‌تر و راهنمای بیشتر
- ✅ ایکون‌های مناسب (⚠️، ❌، ✅)
- ✅ پیشنهاد اقدام بعدی برای کاربر

### مثال‌ها:

#### خطای فیش حقوقی:
```
❌ فیش حقوقی مورد نظر یافت نشد.

[🔙 بازگشت به لیست] [🏠 منوی اصلی]
```

#### خطای اتصال:
```
❌ کد اتصال نامعتبر، استفاده شده یا منقضی شده است.

💡 لطفاً کد جدیدی از پنل وب دریافت کنید.

[🔗 راهنمای اتصال] [🏠 منوی اصلی]
```

## 🎯 نتایج کلی

### بهبودهای UX:
1. ✨ **Navigation آسان‌تر**: کاربران همیشه می‌توانند به منوی اصلی برگردند
2. ✨ **کمتر شلوغی**: با استفاده از دکمه‌ها به جای متن طولانی
3. ✨ **راهنمایی بهتر**: پیام‌های واضح‌تر و ایکون‌های معنی‌دار
4. ✨ **تجربه یکپارچه**: رفتار ثابت در تمام بخش‌ها
5. ✨ **کاهش سردرگمی**: همیشه مشخص است باید چه کاری انجام داد

### بهبودهای UI:
1. 🎨 **ایکون‌های بهتر**: استفاده از ایموجی‌های مناسب‌تر
2. 🎨 **چیدمان منطقی**: دکمه‌های مرتبط کنار هم
3. 🎨 **پیام‌های ساختاریافته**: استفاده از فرمت‌بندی بهتر
4. 🎨 **فیدبک واضح**: همیشه مشخص است چه اتفاقی افتاده

## 📝 نکات مهم برای توسعه آینده

1. **ثبات در طراحی**: همیشه از الگوهای مشابه برای عملکردهای مشابه استفاده کنید
