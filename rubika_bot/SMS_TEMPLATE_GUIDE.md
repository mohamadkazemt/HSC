# راهنمای ایجاد قالب SMS برای کد اتصال روبیکا

## مراحل ایجاد قالب در پنل SMS.ir

### مرحله 1: ورود به پنل
1. به آدرس https://panel.sms.ir/ بروید
2. با نام کاربری و رمز عبور خود وارد شوید

### مرحله 2: ایجاد قالب جدید
1. از منوی سمت چپ، گزینه **"الگوهای پیامکی"** یا **"Templates"** را انتخاب کنید
2. روی دکمه **"ایجاد الگو"** یا **"+ الگوی جدید"** کلیک کنید

### مرحله 3: پر کردن اطلاعات قالب

#### نام قالب:
```
کد اتصال روبیکا
```

#### متن پیام:
```
کد اتصال روبیکا: #CODE#
این کد تا 60 دقیقه معتبر است.
```

#### توضیحات:
- از نماد `#` برای ایجاد متغیرها استفاده می‌شود
- پارامتر `CODE` جایگزین کد اتصال واقعی خواهد شد
- هر متغیر می‌تواند حداکثر 25 کاراکتر داشته باشد

### مرحله 4: تایید و دریافت شناسه

1. روی دکمه **"ثبت"** یا **"ذخیره"** کلیک کنید
2. قالب شما برای تایید به پشتیبانی SMS.ir ارسال می‌شود
3. پس از تایید (معمولاً در کمتر از 24 ساعت)، **شناسه عددی قالب** نمایش داده می‌شود
4. این شناسه را یادداشت کنید (مثلاً: 123456)

### مرحله 5: به‌روزرسانی کد

در فایل `rubika_bot/sms_utils.py` خط 9، شناسه قالب را جایگزین کنید:

```python
RUBIKA_CONNECTION_TEMPLATE = 123456  # شناسه واقعی که از پنل دریافت کردید
```

## مثال قالب پیامک

### قالب در پنل:
```
کد اتصال روبیکا: #CODE#
این کد تا 60 دقیقه معتبر است.
```

### پیامک ارسالی (مثال):
```
کد اتصال روبیکا: a1b2c3d4e5f6g7h8
این کد تا 60 دقیقه معتبر است.
```

---

## نکات مهم

1. ✅ از نماد `#` برای متغیرها استفاده کنید (نه `{}` یا سایر نمادها)
2. ✅ نام پارامتر باید دقیقاً `CODE` باشد (حروف بزرگ)
3. ✅ کد اتصال 32 کاراکتر است (در محدوده 25 کاراکتر نمی‌گنجد)
4. ⚠️ اگر کد 32 کاراکتری است، می‌توانید قالب را به صورت زیر تغییر دهید:

### قالب جایگزین (برای کدهای بلند):
```
کد اتصال روبیکا:
#CODE#
معتبر تا 60 دقیقه
```

یا می‌توانید کد را در دو قسمت ارسال کنید:

### قالب با دو پارامتر:
```
کد اتصال روبیکا:
#CODE1##CODE2#
معتبر تا 60 دقیقه
```

در این صورت باید کد `sms_utils.py` را هم تغییر دهید:

```python
parameters = [
    {"Name": "CODE1", "Value": connection_code[:25]},
    {"Name": "CODE2", "Value": connection_code[25:]}
]
```

## بررسی وضعیت قالب

برای بررسی اینکه قالب شما تایید شده یا خیر:
1. وارد بخش **"الگوهای پیامکی"** شوید
2. وضعیت قالب را بررسی کنید:
   - 🟢 **تایید شده**: آماده استفاده
   - 🟡 **در انتظار تایید**: منتظر بمانید
   - 🔴 **رد شده**: متن را اصلاح و دوباره ثبت کنید

## عیب‌یابی

### خطا: "قالب یافت نشد"
- شناسه قالب را در `sms_utils.py` بررسی کنید
- مطمئن شوید قالب تایید شده است

### خطا: "پارامتر نامعتبر"
- نام پارامتر باید دقیقاً `CODE` باشد
- از نماد `#` استفاده کنید

### خطا: "متن بیش از حد طولانی"
- از قالب دو پارامتری استفاده کنید
- یا کد کوتاه‌تری تولید کنید
