✅ مشکل Sidebar برطرف شد!
========================

🔧 تغییر اعمال شده:
--------------------
شرط‌های permission از منوهای زیر برداشته شد:

1. ✅ درخواست مرخصی
2. ✅ آرشیو مرخصی‌ها

⚠️ توجه مهم:
-------------
- این منوها حالا برای همه کاربران قابل مشاهده هستند
- کنترل دسترسی اصلی در backend (views) انجام می‌شود
- اگر کاربر دسترسی نداشته باشد، هنگام کلیک با خطای 403 مواجه می‌شود

📋 منوی مرخصی حالا شامل:
---------------------------
├─ 📅 مدیریت مرخصی
   ├─ ➕ درخواست مرخصی (همه)
   ├─ 📦 آرشیو مرخصی‌ها (همه)
   └─ ⚙️ مدیریت تأییدکنندگان (فقط superuser)

🚀 اقدام بعدی:
-----------------
1. صفحه را Refresh کنید (F5)
2. sidebar را باز کنید
3. واحد اداری → مدیریت مرخصی را باز کنید
4. باید هر سه گزینه را ببینید!

✨ اگر می‌خواهید کنترل دسترسی در sidebar هم باشد:
------------------------------------------------------
می‌توانید از این شرط‌ها استفاده کنید:
- {% if request.user.is_authenticated %} → فقط کاربران لاگین شده
- {% if request.user.is_staff %} → فقط کارمندان
- {% if perms.leave_reports.add_shiftreport %} → بر اساس permission Django

اما پیشنهاد من: همین‌طور که هست بماند چون کنترل دسترسی در backend امن‌تر است! ✅
